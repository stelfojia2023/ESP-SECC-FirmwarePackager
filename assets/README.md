# 程序图标

`linchr-mascot.ico` 是根据用户提供的领充宣传图中的机器人形象生成的程序图标，包含 16、24、32、48、64、128 和 256 像素尺寸。构建时图标直接嵌入 EXE；运行时不需要单独的图片文件。

图标使用内置 imagegen 生成，再编码为 Windows ICO。生成提示词如下：

> Use case: logo-brand / stylized-concept. Create one premium Windows desktop application icon, based on the provided company poster as a character reference. Faithfully echo the small silver LINCHR robot mascot: a rounded polished silver helmet, a glossy black visor, a vivid narrow horizontal orange-red light on the left flowing into lime-green on the right, a small swept metallic triangular fin and circular side earpieces. Frame the robot's head and upper shoulders large and centered, visually recognizable even at 32 pixels. Render with restrained high-end 3D product-icon craftsmanship, clean curved forms, soft studio reflections and clear silhouette, no busy details. Place it on a simple rich corporate-blue rounded-square tile with a subtle dark-to-bright blue gradient, transparent outside the rounded square. The supplied image is a reference for mascot identity and brand colors only; do not copy the poster layout, background or text. No letters, no brand wordmark, no captions, no watermark. Produce exactly one square icon image, not a grid or mockup.
