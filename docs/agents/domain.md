# Domain docs

本项目采用单一上下文。已有[功能规格](../功能规格.md)和
[V1 格式说明](../V1格式说明.md)继续作为对应产品和包格式的依据。

- 开展领域相关任务时，读取根目录 `CONTEXT.md` 和 `docs/adr/`
  中适用的决策；若不存在，继续使用现行规格和源码，不预先创建空文件。
- 当前已安装的 `domain-modeling` 1.3.2 使用 `GLOSSARY.md`，
  而此配置技能使用 `CONTEXT.md`。若已有相关术语文件，按实际技能读取；
  发现冲突时先报告，不自动复制或改名。
- 新增术语或决策按用户当次授权及适用技能处理，保持现有规格和协作规则。
