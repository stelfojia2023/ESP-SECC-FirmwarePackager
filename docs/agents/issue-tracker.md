# Issue tracker: GitHub

本项目的规格和工作项存放在 GitHub 仓库
`stelfojia2023/ESP-SECC-FirmwarePackager` 的 Issues。

- 优先使用已连接的 GitHub 工具读取 Issue、评论和标签；没有连接器时可使用
  `gh`，并通过 `--repo stelfojia2023/ESP-SECC-FirmwarePackager` 显式指定仓库。
- 需要发布规格时创建 Issue；需要读取工作项时读取正文、评论及标签。
  创建、评论、修改标签和关闭 Issue 均按本次任务授权执行。
- 使用 `gh` 提交多行正文时，将内容写入临时文件并使用 `--body-file`。

## Pull requests as a triage surface

**PRs as a request surface: no.**
