# Triage labels

| 分类角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者待评估。 |
| `needs-info` | `needs-info` | 等待补充信息。 |
| `ready-for-agent` | `ready-for-agent` | 规格已足够清晰，可交由代理处理。 |
| `ready-for-human` | `ready-for-human` | 需要人工处理。 |
| `wontfix` | `wontfix` | 不再处理。 |

标签表示事项状态，不替代本次任务所需的实现、设备操作或提交授权。
