## 本版更新

- 设备升级页新增“读取固件版本”：不选升级包也可按当前设备 IP 和端口查询 PFC、LLC、M4、PLC、ESP32 的运行版本，并分别标注未就绪、不支持查询或不可用。结果表明写入“升级日志”，不弹出对话框；查询失败不显示为有效结果，该操作不发送固件。
- 新增“升级进度”和带时间戳的“升级日志”：按设备确认的字节比例刷新进度条和百分比，记录连接、受理、进度里程碑、设备接收校验及逐目标的升级前／目标／当前版本；100% 只表示包字节已传完，不代表校验通过或安装成功。
- 升级页增加与“开始升级”相邻的“停止升级”占位按钮，当前置灰并标明停止协议未接入；它不能停止设备上的任务。
- 结束应答丢失时，可在本次程序运行期间按界面标明的原设备和原包继续只读查询，不重发；已查到任务结束但版本核对未完成时单独说明，不把版本一致当作此次升级成功。
- 既有固件打包、包头查看和 FTP 上传保留。远程运营平台升级仍未接入。

## 下载和验证

- `FirmwarePackager.exe` 适用于 Windows 10/11 x64，依赖系统 .NET Framework 4.x。可用 `SHA256SUMS.txt` 核对下载文件。
- 发布前执行 `tests/run-tests.ps1` 全量通过（覆盖核心、格式合同、FTP、界面、本地升级协议与 UI、发布版 EXE 的剪贴板、原生拖拽和七色配色点击），并用 `tests/independent_verify.py` 对核心结果做独立核验；主线构建的 CI 检查通过。
- 未在真实设备验证网口、Flash、PLC、重启及平台连接恢复。本地升级功能仅供联调；设备收到并校验通过不代表安装成功。普通 FTP 为明文传输。
