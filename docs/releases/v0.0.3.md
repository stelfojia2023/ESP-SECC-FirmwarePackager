## 本版内容

- 支持 PFC、LLC、M4、PLC、ESP32 固件的选择、拖拽、一键加载、联合包生成和包头查看。
- 支持上传文件到 FTP 和查看 FTP 目录；地址、用户名和密码启动时为空，可自行填写或粘贴含账号的链接。
- 统一“操作说明”和页面页签的尺寸，统一固件输入提示，细化包头及升级页的界面颜色。
- 操作结果按本机时间追加并保留至关闭程序；设备升级页面可自动关联生成的联合包，也可选择本地 BIN。

## 使用和限制

下载下方 `FirmwarePackager.exe`，适用于 Windows 10/11 x64，依赖 Windows 自带的 .NET Framework 4.x。

设备升级页面仅预留本地网口和远程运营平台配置；设备通信协议及平台接口尚未接入，“开始升级”不可用。候选 V1 联合包格式尚未接入现有设备的联合升级流程。普通 FTP 明文传输账号、密码和文件。

本版以 GitHub 主分支的 V0.0.3 源码构建，并经 Windows 构建、文件打包、界面及本机模拟 FTP 回归。未连接实际 FTP、运营平台或设备，未执行设备升级。
