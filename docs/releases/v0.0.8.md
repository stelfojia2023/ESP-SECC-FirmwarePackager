## 本版更新

- 联合包采用 `SECCPKG1` 新布局：4096 字节包头、目录从 `0x28` 开始，固件和整包按 4 KiB 对齐，并校验原始固件及整包 MD5。旧 `0x80` 目录布局的包需要重新生成。
- PLC 固件不限文件后缀，支持识别 `PLC_maya-2.6.7.10.simage` 的名称和完整版本；其他类型仍使用 `.bin`。
- 固件输入支持粘贴已复制的文件或路径，并对剪贴板临时不可用进行短暂重试。

## 使用和限制

下载下方 `FirmwarePackager.exe`，适用于 Windows 10/11 x64，依赖系统 .NET Framework 4.x。PLC 文件按原始字节打入联合包；文件后缀不用于判断内容是否为有效 PLC 固件。

设备升级页面的本地网口和远程平台接口尚未接入，当前不能使用本工具直接升级设备。联合包与真实 PLC 固件及设备的兼容性需单独联调；普通 FTP 明文传输账号、密码和文件。

发布前在 Windows 10 执行完整自动测试、桌面交互及图标比对；使用合成固件和本机模拟 FTP，未执行真实设备升级。
