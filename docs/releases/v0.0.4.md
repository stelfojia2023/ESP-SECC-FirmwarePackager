## 本版更新

- 新增银、蓝、紫、粉、橙、黄、绿七种界面配色。顶部右侧的七个色圈可直接点击，首次启动默认为银色，并记住上次选择。
- 切换配色不会清除已填写的内容和操作记录；颜色名称在悬停时显示，选中项带外环。机器人图标保持不变。
- 七套方案的具体色值、切换规则与验证要求见仓库中的 `docs/七色配色规范.md`。

## 使用和限制

下载下方 `FirmwarePackager.exe`，适用于 Windows 10/11 x64，依赖 Windows 自带的 .NET Framework 4.x。FTP 地址、用户名和密码启动时为空，可自行填写或粘贴包含账号的链接。

设备升级页面仅预留本地网口和远程运营平台配置；设备通信协议及平台接口尚未接入，“开始升级”不可用。候选 V1 联合包格式尚未接入现有设备的联合升级流程。普通 FTP 明文传输账号、密码和文件。

本版通过 Windows 10 本机七色切换、实际 EXE 点击、拖拽、打包、界面及模拟 FTP 测试。未连接实际 FTP、运营平台或设备，未执行设备升级。
