## 本版更新

- FTP 上传成功后生成 ESP-SECC 设备（OCPP 1.6）下载地址，并在“操作结果”上方提供只读地址和“复制”按钮；地址依据本次实际使用的账号、密码、服务器、目录和文件名生成，仅在服务器确认上传完成后显示。
- 按设备限制校验：总长不超过 122 字节，用户名和密码各不超过 47 字节，文件名不超过 80 字节；不支持 IPv6，也不依赖 `%XX` 转义。不满足时保留上传成功结果，只提示无法生成设备地址，不提供可能指向错误文件或账号的链接。
- 地址包含明文 FTP 密码：界面提示、不写入操作结果日志，开始下一次上传时清除；上传失败不提供地址。
- 既有固件打包、包头查看、FTP 上传与目录查看、本地升级页和七色配色保留。

## 下载和验证

- `FirmwarePackager.exe` 适用于 Windows 10/11 x64，依赖系统 .NET Framework 4.x。可用 `SHA256SUMS.txt` 核对下载文件。
- 发布前执行全部自动测试组及 `tests/run-tests.ps1` 全量通过（覆盖核心、格式合同、FTP、界面、本地升级协议与 UI、发布版 EXE 的原生拖拽、七色点击和剪贴板，以及独立 EXE 的 FTP 下载地址与剪贴板），并用 `tests/independent_verify.py` 对核心结果做独立核验。
- 桌面测试针对本机剪贴板文件拖放、桌面焦点和窗口遮挡的争用增加了有界重试与等待，只修改测试代码，不改变产品行为。
- 未在真实设备验证网口、Flash、PLC、重启及平台连接恢复；生成的设备下载地址未在真实 OCPP 平台或设备上验证可下载。普通 FTP 为明文传输。
