## 本版更新

- 设备升级页新增本地 TCP（LUP1）客户端：选择并校验联合包、传输、查询升级任务及目标版本。
- 如果设备重启后查不到任务、但报告的版本与目标一致，界面仍显示结果未确认，可以继续查询；不会把版本一致当作此次升级成功。
- 既有固件打包、包头查看和 FTP 上传保留。远程运营平台升级未接入。

## 下载和验证

- `FirmwarePackager.exe` 适用于 Windows 10/11 x64，依赖系统 .NET Framework 4.x。可用 `SHA256SUMS.txt` 核对下载文件。
- [Windows CI](https://github.com/stelfojia2023/ESP-SECC-FirmwarePackager/actions/runs/45027031712) 的主线构建及所选测试通过。相同源码树的 [PR #19](https://github.com/stelfojia2023/ESP-SECC-FirmwarePackager/pull/19) 记录了全量自动检查、Windows 桌面回归重跑和带替身的本地 TCP 联测；桌面回归首次出现多文件粘贴断言失败，原因未确认。
- 未在真实设备验证网口、Flash、PLC、重启及平台连接恢复。本地升级功能仅供联调；设备收到并校验通过不代表安装成功。普通 FTP 为明文传输。
