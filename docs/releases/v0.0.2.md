## 本版内容

- 支持 PFC、LLC、M4、PLC、ESP32 固件选择、拖拽、一键加载与联合包生成。
- 支持上传文件到 FTP、查看 FTP 目录及查看生成包的包头。
- 顶部提供“固件打包”“设备升级”和“! 操作说明”；升级页可自动关联生成的 BIN，也可选择其他本地 BIN。
- 操作结果按本机时间追加显示，程序运行期间保留；关闭程序后重新开始记录。

## 使用和限制

下载下方 `FirmwarePackager.exe`，适用于 Windows 10/11 x64，依赖 Windows 的 .NET Framework 4.x。

设备升级页面目前仅预留本地网口和远程运营平台配置；设备通信协议及平台接口尚未接入，“开始升级”不可用。候选 V1 联合包格式尚未接入现有设备的联合升级流程。普通 FTP 明文传输；默认 FTP 密码内置在程序和源码中，持有者可读取。

本版已通过 Windows 10 构建、UI、文件打包和本机模拟 FTP 回归；未连接实际 FTP、运营平台或设备，未执行设备升级。
