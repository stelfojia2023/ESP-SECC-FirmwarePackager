# V0.0.3 变更

工程版本从V0.0.2升级至V0.0.3，包格式V1不变。初始合并提交未发布 GitHub Release；发布状态以 GitHub Release 页面为准。

## 本次范围
- FTP地址、账号、密码默认均留空，由用户填写；保留文件选择、上传、目录查看等功能。
- “操作说明”按钮180×40，与左侧两个页签相同。
- 五类固件卡共用提示“拖入固件或粘贴路径”。
- 包头底色/错误色归入Field/Error tokens，定位高亮保留原颜色并命名HeaderHighlight。
- 升级页选择文件夹按钮使用ButtonIcon。
- 版本号及现行测试同步到0.0.3；字体/字号与System DPI机制不改。

## 安全与验证边界
从当前源码移除默认连接值，不清除Git历史、旧构建或历史Release。若旧密码仍有效，需由拥有者另行处理其生命周期；本次不擅自操作服务器、吊销凭据或改写历史。

自动化验证应涵盖：三个默认字段空且密码掩码保留、按钮同尺寸、五类提示一致、原格式/边界/FTP回归、包头与DPI诊断。最终以本次Windows CI结果为准；不能从修改测试断言推断已通过。真实125%/150%系统缩放、跨屏、真实FTP服务器仍不是本次验证范围。
