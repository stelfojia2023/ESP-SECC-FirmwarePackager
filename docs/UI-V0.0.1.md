# V0.0.1 界面与交互

## 设计原则

- 实用优先。功能不减，只移除大幅品牌横幅、重复标题和说明。
- 暖灰白底、轻浮卡片，组内紧凑、组间宽松。
- 按钮比例适中，有轻微起伏、悬停和按压反馈；避免细长按钮。
- 文件与元数据在左，概览、输出和操作结果在右。偏移详情默认折叠；FTP 点击后用模态弹窗覆盖主窗口。
- 点击使用轻巧 B 音色，成功、失败分别提示。音效默认启用，不设置选择开关；结果始终可见；FTP 弹窗明确显示上传状态，主入口同步显示结果。
- 音效为本项目原创合成资源，内嵌 EXE，不依赖旁置 WAV。

## 功能边界

保留五类输入、拖放与粘贴、名称/版本编辑、清除、大小/预算/偏移预览、生成、打开校验和 FTP 上传。

没有改变 `Packager.cs`，包格式仍为 V1。FTP 新增独立普通文件入口：生成成功后默认最近生成的联合包，并在上传前保持 V1 校验；未生成时文件框为空、提示拖拽或浏览，也可选择任意本地文件直接上传，不强加包格式和 6 MiB 限制。关闭弹窗不会丢失主界面或已填 FTP 内容；上传中冻结来源和目标并阻止关闭弹窗，完成后恢复。普通文件采用流式传输，选择模式和确认框明确标示是否校验联合包。工具版本 V0.0.1 独立于包格式；V1.0.0 留作后续正式发布。设备端尚未接入联合包解析；6 MiB/2.5 MiB 候选设备配置不因 UI 更新成为已部署能力。界面底部保留设备支持与 MD5 规则入口，FTP 风险说明和上传确认保留。

## 构建与验证

- `build.ps1`：Windows 原生 .NET Framework 编译，三个声音资源内嵌，产出 `dist/FirmwarePackager.exe`。
- `.github/workflows/windows-build.yml`：只读权限，官方 checkout/upload-artifact 固定版本；构建、核心、FTP、UI 控件契约及独立 Python 校验，不部署。
- `tests/UiContractTests.cs`：验证版本、功能控件、声音资源、折叠/展开、默认音效开启与无音效开关，以及绘制，不替代真实鼠标/键盘/拖放测试。
- `tests/run-tests.ps1`：仍需解锁的真实 Windows 桌面，运行原有完整交互回归。

本次本地环境为 Linux：Mono 交叉编译成功，参考向量独立验证通过，FTP 原30项及新增独立文件场景共62断言通过；核心测试通过组合/预算/损坏阶段后在 Windows 硬链接 API 停止，因此不标记完整核心通过。Linux Mono 控件契约与临时显示会话的布局截图已检查；此结果不等于真实 Windows GUI、DPI、原生拖放或音频体验通过，这些仍待实机确认。Windows CI 结果以对应提交的运行记录为准，不沿用旧版 evidence。
