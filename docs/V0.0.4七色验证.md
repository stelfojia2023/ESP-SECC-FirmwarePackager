# V0.0.4 七色验证

## 基线与范围

以独立工具仓库 GitHub 主分支提交 `809a5ef710c75536f0b313fa00f98cc60eacdd94`（V0.0.3）为基线，先写 [七色配色规范](七色配色规范.md)，再实现七色切换。默认银色；顶部右侧色圈直接切换并记住上次选择，未改变机器人图标或候选联合包格式。

## Windows 本机验证

- Windows 10 原生构建 V0.0.4 x64 EXE，SHA-256：`4f281e6c9fc242ed58e0d4a41c976ece3d53a021f7aaafc1c9b7d9bc49a10323`。
- 七色测试 400 项断言通过：规范色值、实际控件和弹窗颜色、对比度、色圈无障碍名称、选中状态、输入与错误日志保留、无效设置回退、保存失败提示及新进程恢复选择。
