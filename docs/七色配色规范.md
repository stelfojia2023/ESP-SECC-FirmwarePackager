# 固件打包工具七色配色规范

## 范围与设计原则

以苹果官网 iMac 银、蓝、紫、粉、橙、黄、绿七种外观作为色相参考，针对本工具的卡片、文字和输入框重新调配；以下是本工程的 UI 色值，不声称是苹果官方色号。银色沿用 V0.0.3 的现有视觉基线。实现与验证情况见 [V0.0.4 七色验证](V0.0.4七色验证.md)。

七套方案保持浅色、低饱和、细边框和轻微层次。颜色应帮助区分页面与控件，不以大面积高饱和色覆盖信息；文字保持清晰，错误保持红色。字体、布局、固件操作和程序机器人图标不因切换配色而改变。

## 通用文字与反馈

七种方案共享：正文 Ink `#30363C`，次级文字 Muted `#626A73`，错误 Error `#B53239`，成功 Success `#1D7858`；包头定位高亮 `#E1D59C`。错误和成功始终同时显示文字，不仅依赖颜色。

阴影、亮边、禁用、悬停和按下计算沿用 [视觉规范](视觉规范.md)；现有按钮文字、字号和可访问名称保持不变。对比度按 sRGB 相对亮度计算：在实际使用的文字与 Canvas、Card、CardBottom、Field、按钮底色组合上验证；正常文字和错误文字目标不低于 4.5:1。系统禁用文字按原有系统主题处理，单独检查可辨识性。

## 选择与保存

1. 首次运行或设置不存在、无效、不可读取时使用银色；不在启动时强制弹窗选择。
2. 顶部右侧设置独立于导航按钮的七个色圈，直接点击切换；不提供“配色”按钮或下拉菜单。色圈从左到右为银、蓝、紫、粉、橙、黄、绿，当前颜色以外环标记；悬停显示颜色名称，键盘焦点可辨识。选择后立即更新打包页、升级页和随后打开的应用内弹窗；Windows 系统文件选择器和系统消息框沿用系统外观。
3. 关闭再打开后恢复上次选择；仅将配色标识存入本机用户的 `%LOCALAPPDATA%\\LINCHR\\FirmwarePackager\\appearance.txt`。不保存固件路径、FTP 账号、密码或升级配置。
4. 如果无法保存，本次窗口仍使用所选颜色，并清楚提示下次启动可能无法恢复。切换配色不得清除输入、已生成文件、操作结果、历史错误颜色或正在进行的 FTP 状态。
5. 色圈可使用鼠标及键盘操作，暴露颜色的无障碍名称和选中状态；不单靠颜色区分当前选择。各入口和文字不得在最小窗口或已验证的缩放条件下被裁切。

色圈色值：银色 `#C9CED2`、蓝色 `#B4CEE9`、紫色 `#C5B9E4`、粉色 `#EAC0CF`、橙色 `#F2C6AA`、黄色 `#ECDC9B`、绿色 `#B6D8BF`。色圈为切换入口，其余界面色值仍按上面的两张表执行。

## 验收

- 测试七套色值和实际控件对应关系，银色与 V0.0.3 基线一致；切换两页及应用内弹窗使用同一方案。
- 验证首次启动、七色切换、重复切换、关闭重开、无效或不可写配置、日志和输入保留；计算实际文字组合的对比度。
- 在 Windows 上运行原有打包、FTP 模拟、拖拽、包头及升级页回归，并确认机器人图标未改变。不同系统缩放或真实设备未验证时明确标注。
