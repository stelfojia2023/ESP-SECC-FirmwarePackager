# 字体与文字清晰度规范

本文件记录本工程当前实现的字体、字号和 DPI 处理方式；实际字体可因系统安装和回退而不同。

## 当前实际字体

所有下列字号单位均为 **pt（Point，磅）**，不是 px。代码的 Font 构造未显式指定单位时默认使用 Point。常规 = FontStyle.Regular，加粗 = FontStyle.Bold。

| 使用位置 | 字体族 | 字号 | 字重 | 实现来源 |
|---|---|---:|---|---|
| 主窗口、普通字段、FTP字段/标签、动态列表、操作结果日志、升级页普通文字 | Microsoft YaHei UI | 9.5 pt | 常规 | MainForm构造设置，未单独指定的子控件继承 |
| 顶部“固件打包”“设备升级”页签 | Microsoft YaHei UI | 10.5 pt | 当前页加粗，其余常规 | pageTabFont/pageTabSelectedFont、ShowUpgradePage |
| 顶部“操作说明”按钮 | Microsoft YaHei UI | 10.5 pt | 常规 | PreparePageTab |
| PFC / LLC / M4 / PLC / ESP32 类型标签 | 主窗口实际 FontFamily（通常为 Microsoft YaHei UI） | 12 pt | 加粗 | 创建五卡时覆盖标签字体 |
| 区域标题，例如操作结果、升级文件 | Microsoft YaHei UI | 11 pt | 加粗 | TitleLabel / UpgradePage.Title |
| 主要操作按钮，例如一键加载、包生成、上传到FTP | Microsoft YaHei UI | 9 pt | 加粗 | StyleButton(primary=true) |
| 辅助操作按钮，例如一键清理、查看包头、打开FTP目录 | Microsoft YaHei UI | 9 pt | 常规 | StyleButton(primary=false) |
| 升级页本地/远程模式按钮 | Microsoft YaHei UI | 9 pt | 选中加粗，否则常规 | UpgradePage.Style |
| 操作说明正文 | 主窗口 Font | 9.5 pt | 常规 | ShowHelp显式赋值 Font=Font |
| FTP目录弹窗普通文字 | Microsoft YaHei UI | 9 pt | 常规 | FtpDirectoryViewer构造 |
| 包头弹窗普通文字与定位按钮 | Microsoft YaHei UI | 9 pt | 常规 | HeaderViewer构造与继承 |
| 包头十六进制 / ASCII 内容 | Consolas | 10 pt | 常规 | HeaderViewer的hex.Font |

图标按钮主要由路径绘制图标，不依赖某个符号字体。原生标题栏、系统文件选择器字体由 Windows 控制。

代码中的8.5 pt类型标签会在五卡构建时被12 pt覆盖；8.3 pt的SizeLabel已隐藏、大小改在动态列表显示。两者不是当前可见界面的字号规范。

## 字体供应与渲染

- 不随EXE分发或嵌入字体；依赖Windows已安装字体。字体族缺失时.NET/Windows可能替代，缺失字形也可能由系统回退。请求的字体名不等于所有机器实际渲染字体。
- 主界面中文优先延用Microsoft YaHei UI，不把Segoe UI当成必然覆盖中文的替代。Consolas仅用于包头等宽数据。
- 自绘按钮文字使用TextRenderer；应用入口使用SetCompatibleTextRenderingDefault(false)。原生TextBox/RichTextBox继续走原生控件文本，不为视觉统一改成位图文字。
- 不强制改变用户Windows ClearType/字体平滑设置。当前CI诊断观测ClearType已启用，不保证用户所有设备相同。
- 文字颜色沿用 UiColors.Ink / Muted / Error；不要通过降低透明度“变细”。当前色值见[七色配色规范](七色配色规范.md)。

## 当前 DPI 机制

1. `app.manifest`声明 `dpiAware=true` 与 `dpiAwareness=system`，由 `build.ps1` 的 /win32manifest 编入EXE。
2. 主窗口、FTP目录窗和包头窗使用AutoScaleMode.Dpi；布局按WinForms的DPI机制处理，pt字号不能再手动乘一遍缩放比例。
3. 按钮图标单独按Graphics.DpiX / 96缩放；现有描边、阴影、圆角使用设备像素，见视觉规范，不要擅自再整体缩放。
4. System aware不是PerMonitorV2。它不能承诺混合DPI多屏间移动、会话中改缩放后始终清晰；必要时在目标显示器/缩放配置下重启程序。
5. 此处没有升级.NET目标框架，也没有新增动态DPI布局逻辑；业务功能、布局结构和FTP设置不变。

## 后续新增界面如何遵循

- 普通字段/日志继承主窗口9.5 pt；新页面不要自行改成系统默认字体、宋体或将“9.5”当像素。
- 使用现有标题/按钮辅助方法；主要动作9 pt加粗，辅助动作9 pt常规，标题11 pt加粗。不要为了突出某个按钮随意换字体族。
- 顶层弹窗显式声明其字体和AutoScaleMode，与上表相同类别复用；无需把所有文字都加粗。
- 保留可编辑文本、键盘焦点及原生选择复制功能；长路径允许原有滚动/省略，不得压缩字体掩盖布局缺陷。
- 改字号前先检查中文、英文、长路径、错误消息、禁用及选中状态；至少验证100%、125%、150%目标环境的按钮/字段/日志不裁切。未做系统缩放实测必须标“未验证”。
- 字体与样式以代码为准，规范同步更新；新增例外需写明使用场景、实际单位和验证证据。所有新文件不得写入连接凭据。
