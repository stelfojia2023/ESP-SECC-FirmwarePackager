# 使用说明

双击 `FirmwarePackager.exe` 启动。程序支持 Windows 10/11 64 位，依赖系统的 .NET Framework 4.x；打包无需联网，FTP 操作需要连接服务器。固件及输出路径可包含中文和空格。

## 选择固件

在“固件打包”页，可将单个固件文件拖入对应的长框，或点击长框后按 Ctrl+V 粘贴已复制的文件或路径，也可通过浏览按钮选择。PFC、LLC、M4、ESP32 须为 `.bin`，PLC 不限后缀；五类可选 1～5 类，每类一个，一次粘贴多个文件会提示并保留原选择。名称默认取文件名去掉扩展名；普通版本从下划线后的 `V` 或 `v` 开始，取到下一个下划线或点之前，例如 `PFC_ABC_V001B02.bin` 识别为 `V001B02`。PLC 文件 `PLC_maya-2.6.7.10.simage` 识别为名称 `PLC_maya-2.6.7.10`、版本 `maya-2.6.7.10`；`maya` 忽略大小写，版本保留点号并取至下一个下划线；没有独立后缀的 `PLC_maya-2.6.7.10` 同样保留完整版本。如果实际后缀本身为纯数字，工具无法仅凭文件名与版本区分，可手动修改名称和版本。未识别到版本时，可手动补填。名称和版本各最多 39 个 UTF-8 字节，超长不截断。

“一键加载”只扫描所选文件夹当前层；PLC 文件不限后缀，其他类型识别 `.bin`。每类仅有一个有效匹配文件且版本可识别时才自动更新；同类重复、缺版本、空文件、超限或无效项会跳过并保留原选择。“一键清理”不删除磁盘文件，也不清空 FTP 配置、输出位置或操作记录。

| 固件类型 | 原始文件预算或上限 |
| --- | ---: |
| PFC、LLC | 各 250 KiB 预算 |
| M4 | 512 KiB 预算 |
| PLC | 2 MiB 预算 |
| ESP32 | 2.5 MiB 上限 |

空文件、ESP32 超限文件和超过 6 MiB 的联合包会被拒绝；联合包上限包含包头和对齐填充。PFC、LLC、M4 或 PLC 超预算时显示告警，仍可在整包允许范围内生成。这些工具限制不代表设备已具备相应分区。

## 生成和查看

选择输出 BIN 的保存位置并点击“包生成”。输出不能与输入固件指向同一文件；已有输出会要求确认替换。程序先写入同目录临时文件，经校验后发布到目标路径；失败不会报告成功。成功后，结果区显示路径、总大小及固件信息。列表中的偏移相对于联合 BIN 起点，不是芯片烧录地址。

点击“查看包头”可只读查看本次生成包的前 4096 字节，并定位 `0x0000～0x0FFF` 的地址。文件缺失、长度不足或包头与生成时不同会报错；该入口不能独立打开已有包。

新包使用 `0x28` 目录布局，不能与旧工具的 `0x80` 布局混用；旧包需要重新生成。

## FTP

地址、用户名和密码启动时为空。可分别填写，也可粘贴 `ftp://用户名:密码@服务器:端口/目录` 自动分离账号；账号或密码中的 `@`、`:` 等 URL 特殊字符需先百分号编码。密码在界面遮罩，填写值不会保存到下次启动。

生成后默认选中刚生成的联合包；也可选择普通本地文件。“上传到 FTP”需确认目标，工具会在目录后追加所选文件名：联合包上传前会再次校验，普通文件不套用包格式及 6 MiB 限制。只有收到服务器最终成功应答才显示成功；这不包含远端回读校验，也不代表设备已升级。普通 FTP 明文传输账号、密码和文件，服务器上的同名文件可能被覆盖。

“打开 FTP 目录”无需选择本地文件。已选择文件时，仅按区分大小写的名称比较是否存在同名条目，不验证远端类型或内容；目录读取支持 UTF-8 及 GBK，超过 10,000 个条目或 4 MiB 时提示无法完整显示。

## 设备升级

源码候选提供本地 LUP1 升级；设备侧合同与真实设备尚未完成联调。现场须使用已启动 ETH、可信且逐台隔离的维护网络，不并发使用会直接写暂存区的串口下载命令。远程运营平台升级仍未接入。

新生成的联合包自动关联到“设备升级”页，也可拖入或选择已有 BIN。检查包内目标和版本，确认设备 IP／端口（默认 `192.168.198.50:8090`）后点击“开始升级”。工具再次校验并固定同一份包数据；第一步确认框提示新任务可能替换设备上等待安装的旧包。随后查询设备状态和升级前版本，第二步确认目标与当前版本后才开始发送。已插枪或设备状态未知时不能发送。当前 PLC 版本格式和查询长度有限制，出现提示时由人员决定是否继续。

“超时设置”可调整连接及普通查询、数据块、开始及结束、等待版本的时间，默认分别为 5 秒、10 秒、120 秒和 600 秒，仅在本次会话有效。进度表示设备已确认的字节数；接收并校验通过不等于安装完成。工具每 5 秒查询实际目标版本；版本一致只表示版本号一致，不证明本次已经重新写入。

传输中断、失败或开始应答丢失时，不自动重发或续传；结束应答丢失时先用本次任务 ID 查询，无法关联时显示无法确认。等待超时不取消设备的安装，可在本次程序运行期间点击“继续等待”，只重新查询。期间生成的新包会在本次等待结束后关联为下次候选，不会自动发送；若新任务开始时被设备拒绝，仍可尝试继续查询旧任务。关闭程序后不恢复旧任务。

设备负责暂停和恢复运营平台连接；工具不直接操作平台。云端下载可能暂时占用设备线程，连接或应答超时后由人员稍后重试。传输中关闭程序会要求确认，关闭可能中断接收；设备已接收的安装可能继续。

## 界面与记录

顶部右侧七个色圈可直接切换配色，悬停显示颜色名称；首次使用为银色，之后恢复上次选择。操作结果按本机时间追加，切换页面、清理输入或配色不会清除；关闭程序后不保存记录。

格式与校验规则见 [V1 格式说明](V1格式说明.md)。`test-vectors` 中的文件是合成测试数据，不能用于设备升级。
