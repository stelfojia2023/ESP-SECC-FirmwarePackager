# 固件联合打包工具使用说明

双击 `FirmwarePackager.exe` 启动。支持 Windows 10/11 64 位，依赖系统的 .NET Framework 4.x；无需安装开发工具。打包和校验无需联网，FTP 上传需要连接服务器。

**当前 V1 包格式供评审使用，现有设备尚未接入联合包解析，不能直接用于现有设备升级。** 界面中的 6 MiB 暂存区与 2.5 MiB ESP32 应用槽均为候选方案。

1. 将 BIN 拖入对应类型的输入框，或粘贴、输入文件路径，也可以点击“浏览”。可选择 1～5 类，每类一个文件，未选类型不会被写入包。
2. 检查并按需修改默认固件名称，逐项手动填写版本，例如 `V000B01D15`。
3. 检查预览中的类型、名称、版本、文件大小和包内偏移，以及总大小与警告。包内偏移从联合 BIN 开头计算，不是目标芯片的烧录地址。
4. 点击“选择位置”，选择输出 BIN；点击“生成联合包”。成功后在下方查看文件路径、总大小、整包 MD5 及各固件 MD5。
5. 如需查看已有包，点击“打开并校验联合包”。校验失败会显示具体原因。
6. 如需上传当前输出 BIN，粘贴 `ftp://用户名:密码@服务器:端口/目录` 到“FTP 地址”，工具会自动分离账号和密码；也可分别填写地址、用户名和密码。密码在界面上遮罩，仅保留在当前窗口，不写入文件。账号或密码中的 `@`、`:` 等 URL 特殊字符需先百分号编码。
7. 点击“上传到 FTP”，核对目标地址并确认。工具将当前输出文件名追加到服务器目录，重新校验本地包后上传；收到服务器最终成功应答才显示成功，失败时显示原因。服务器上同名文件可能被覆盖；普通 FTP 会明文传输账号、密码和文件。成功不包含远端回读校验，也不代表设备升级成功。

ESP32 原始固件不得超过 2.5 MiB，联合包包括包头与填充不得超过 6 MiB。PFC、LLC、M4、PLC 超过建议预算时会提示，但总包大小合规时仍允许打包。文件为空、不可读取、未填版本、文本超过 UTF-8 字节限制等情况会报错。

整包 MD5 的计算会将包头中的整包 MD5 字段视为全零，因此不同于直接对最终 BIN 执行普通 `md5sum`。MD5 只检查数据一致性，不能验证发布者身份。

`V1格式说明.md` 描述待评审格式的字节布局；`test-vectors` 是合成测试样包，不能用于升级。完整源码、构建和回归说明位于独立工程目录。
