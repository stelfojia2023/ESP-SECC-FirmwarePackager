# 工程版本提交约定

本约定仅用于本工程：**提交一个新的工程版本时必须升级版本号，并在PR说明中写明旧版本 → 新版本及主要变化。** 不是每个普通提交、测试修正或同一PR内的小步修改都要增号。

- 当前新版本：V0.0.2 → V0.0.3；包格式V1不变。
- 一个版本内的准备、验证和修正提交可共用该目标版本。
- 窗口版本、AssemblyVersion、AssemblyFileVersion、app.manifest、构建产物名与现行测试断言保持一致。
- README说明当前版本、实际可取得的产物与历史Release区别；历史验证文档/测试夹具不要改写为新版本，避免伪造过去证据。
- 工程升级版本不等于授权发布GitHub Release。本次不发布Release；只有明确要求发布时才更新发布元数据和校验摘要。
- .github/release.json 当前是历史v0.0.2已发布元数据，不是工程版本权威来源。本次不得使用它发布V0.0.3。
- 发布前核对实际构建源提交、测试结果、EXE版本及摘要。不把旧dist或历史Release资产误称为当前新版本。
