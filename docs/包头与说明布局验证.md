包头弹框根据当前字体和 RichEdit 中完整一行的实际宽度，以及地址导航控件所需宽度，计算默认和最小窗口宽度；仍可放大，保持地址定位、只读内容、16 字节及 ASCII 展示。操作说明的现有图标移至右上方文件夹加载卡片，去掉单独占用的顶部行，并相应收紧默认窗口高度。

## 验证

- Windows 10 x64 下使用系统 .NET Framework 编译器构建，EXE SHA-256：`61a112a7e7c5ad3c2285085d5a967e1010376f0fb56a8a7434700ee08d2521ec`。
- 本机测试中包头弹框默认宽度由 880 调整为 615 逻辑像素；十六进制及 ASCII 一行在控件内完整可见，文字右侧约留 20 逻辑像素。宽度随实际字体和导航内容计算，并非要求所有环境都为 615 像素。
- 包头测试 4,150 次断言通过，包括完整内容、有效和无效地址、首末字节及高亮、最小窗口完整显示。UI 契约 241 次断言通过，包括说明图标在默认和最小窗口内可见、与文件夹按钮不重叠，以及点击说明和查看包头后弹框的内容。
- 完整回归包含核心 260,552 次断言、31 种固件组合、FTP 62 次和文件名 74 次断言；独立读取器核验了组合、上限和已有样包。Windows 原生交付 EXE 以及仅携带 EXE 的副本均实际触发说明和包头弹框，并通过拖拽、生成、校验和旧 V1 样包测试。
- 领充 ICO 和 `src/UiControls.cs` 与基线字节一致；新旧 EXE 提取的七种尺寸图标逐像素一致。操作说明图标的文字、尺寸和提示保持不变。

`evidence/ui-dialog/main-win10-125.png` 和 `header-win10-125.png` 是 Windows 10、125% 缩放下，测试宿主加载交付 EXE 中对应窗体并截取自身前台客户区的画面。包头画面使用全零合成数据，未读取实际用户固件；两张图不包含用户账号。

本轮未实测 Windows 11、其他系统缩放比例、真实 FTP 服务器或设备升级。旧 `evidence/ui-compact/SHA256SUMS` 等为对应历史版本的清单；当前文件和证据见 `evidence/ui-dialog/SHA256SUMS`。日志统一为 UTF-8、LF 行尾，去除行尾空格和末尾空行。
