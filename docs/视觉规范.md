# 界面视觉规范

本规范用于不同 Agent 对同一工程作一致实现与验收。银白浅灰为默认方案；其余六种配色与顶部色圈入口见[七色配色规范](七色配色规范.md)。功能、字体、固件格式和 FTP 规则均不因切换配色而改变。

## 单一权威来源

- 七种配色的色值见[七色配色规范](七色配色规范.md)，实现由 `src/MainForm.cs` 的 `UiPalette` 和 `UiColors` 提供。禁止在新页面复制近似色。
- 按钮材料及状态算法：`src/UiControls.cs` 的 `UiMetrics`、`RaisedButton.OnPaint`。
- 卡片、输入框绘制：`src/MainForm.cs` 的 `UiSurfaceMetrics`、`SectionCard`、`SoftField`。
- 布局与排版：`MainForm` 的 `PreparePageTab`、`SetupMainButton`、`RightActions`、`CardLayout` 及 `UpgradePage`。复用这些组件而非按效果图猜尺寸。
- 规范与代码如有冲突，先报告，不以文档覆盖业务逻辑。

## 材料、状态与算法

混色 `Blend(A,B,t)` 为每个 RGB 通道 `Round(A+(B-A)*t)`，不应用未知滤镜。按钮从 BackColor 获取主/辅/图标底色 F：

- 普通：上缘 `Blend(F,White,0.48)`，下缘 `Blend(F,#646B72,0.08)`；垂直线性渐变。
- hover：先将 F 与白混合0.10，再使用普通渐变。不通过增加尺寸表示 hover。
- pressed：可用且鼠标/空格按下时向下2设备像素，上缘混白0.08、下缘混暗0.12；松开、失去焦点/捕获后复位。
- disabled：F先与 #EBECEE 混合0.65，无阴影；字/图标采用 Windows `SystemColors.GrayText`，其值随系统主题而定，不伪造固定HEX。不可用控件仍通过原生Enabled语义禁用。
- 外边线：Border与Ink混合0.15，按下为0.24；1设备像素。
- 内亮边：内缩1设备像素；垂直alpha220→18的白线，按下为100→18。
- 阴影不是高斯模糊：从外到内绘制y偏移3、2、1设备像素的同形路径，alpha6、11、16。按下仅y偏移1、alpha12；无模糊半径参数。
- 按钮圆弧直径12设备像素，即半径6（小按钮上限为短边）。图标上限22×DPI/96设备像素且受按钮可用区域约束。
- 键盘焦点沿内缩4设备像素区域绘制原生虚线，不删除焦点提示。
- 卡片圆弧直径22（半径11）设备像素；阴影偏移(1,3)，单层alpha22，无模糊；垂直渐变由当前配色的 CardTop → CardBottom 决定。上沿1px亮线，左右避开12px圆角。
- 输入框圆弧直径9（半径4.5）设备像素；边线1，聚焦1.5设备像素并变为Blue；顶部1px淡暗内线。原生TextBox保持平面Field底色，不能为了全表面渐变牺牲选择/输入/无障碍。

## 布局与排版（沿用，不在本次改动）

完整字体类别、pt单位、继承/回退及现行System DPI机制见[字体与文字清晰度规范](字体规范.md)。当前字号未放大，后续同类控件遵循该表。

- 主字体 Microsoft YaHei UI 9.5pt；操作按钮9pt，主要操作加粗；类型标签12pt加粗；顶导航10.5pt，当前页加粗；区标题11pt加粗。
- 主按钮设计尺寸180×40逻辑像素，RightActions固定两轨186，边距(3,5,3,3)。导航原尺寸及帮助按钮180×40不改。
- 主工作区左右55%/45%；外边距(18,4,18,14)；左五卡内边距(12,8,12,10)、卡间下6；右卡内边距同左、下8，左右组间保留原8+6。
- 字段包裹内边距：单行(8,5,8,3)，多行(9,7,9,7)，外边距3；不通过额外解释文字撑大界面。
- 小屏用原有页面滚动；错误结果红色并附文字；不以换肤改变字段可编辑性、拖拽、列表行数与结果展示规则。
- 尺寸/间距由WinForms AutoScaleMode.Dpi缩放；绘图笔宽、阴影、圆角使用上述设备像素，刻意保持细轮廓。图标按DPI缩放。不可对绘制参数再整体缩放一次造成重复放大。

## 复用与验收

新增同类操作必须使用RaisedButton，卡片用SectionCard，输入用SoftField，颜色来自UiColors。不要新增炫彩、厚重3D、模糊玻璃滤镜、巨幅标题或无用途装饰。选中、焦点、禁用、错误均须保留文字/语义，不只靠淡颜色。

1. 代码回归：核心格式、文件名、大小边界、FTP、包头、升级页和原有UI契约继续通过。
2. `UiContractTests` 增加文字/次级/错误色对浅底的WCAG相对亮度对比度检查（>=4.5）。边框仅用于分组，不声称达到所有非文字3:1要求；键盘focus和文字仍可辨。
3. 保存真实Windows控件渲染和96/120/144/192DPI模拟绘制。模拟图不是切换系统DPI，也不替代用户设备上的清晰度、原生输入和拖拽检查。
4. 对照当前配色：背景和卡片保持柔和层次，按钮有清晰的可点击状态；结构、尺寸、文案不随配色改变。
5. 最终审美听感、系统字体/DPI、显示器色差需实机确认；不宣称像素级复刻效果图。所有尚未实测项在交付说明列明。

## 界面细节

操作说明与两页签均180×40；顶部右侧为七个直接切换的色圈。固件卡提示为“拖入固件或粘贴路径”。包头字段底色和错误色使用 Field／Error，定位高亮使用 HeaderHighlight；升级页文件夹按钮使用 ButtonIcon。
